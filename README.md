# Live VIP — Offline 3D Live Wallpaper Maker

An Android app that imports prepared wallpaper projects (`.mwproj`) and renders them as a real
Android live wallpaper with tilt-driven parallax, glow, particles and rig-based motion.

Everything runs on the phone. There is no AI service, no cloud processing, no account, no analytics,
and no `INTERNET` permission.

## What works

* **Import** a `.mwproj` ZIP through Android's document picker. The archive is checked for size, unsafe
  paths, file types, PNG dimensions, manifest fields and GPU memory before it is added to the library.
  A bundled sample imports on first launch, or from the Import screen.
* **Library**: thumbnails, preview, effects, rename, duplicate, delete, and choose the active wallpaper.
* **Live preview** with the real OpenGL ES renderer. It uses the rotation sensor (gyroscope and accelerometer
  fused by Android) when available, and touch-drag otherwise.
* **Effects**: outer and inner glow (color, intensity, radius, pulse), fire / sparks / magic / ambient
  particles, background blur, brightness, contrast, saturation and tint, and rig motion strength.
* **Motion & depth**: parallax strength, perspective, depth scale, damping, motion limit, idle drift and
  axis inversion. Edges are covered by a zoomed background with blurred edge fill.
* **Performance**: Low / Balanced / High presets change render resolution, frame cap, particle count and
  glow samples. Rendering stops while the wallpaper is hidden.
* **Apply**: opens Android's own live-wallpaper preview. The app shows "active" only after the system
  reports that this wallpaper is set.

### Limits (stated plainly)

* The app does **not** segment people or objects. Hair, cloth, cape and sword motion only exists when the
  project supplies separate layers and masks (see the format spec).
* A single flattened PNG gets procedural parallax, particles and background effects. Glow applies to
  character layers only.
* `mesh` files are validated but **not rendered** yet. Skeletal or mesh deformation is not implemented.
* Home screen vs. lock screen selection is made in Android's own wallpaper screen; the app cannot preselect it.
* OpenGL ES 3.0 is requested first. Devices without it use ES 2.0. Shaders are GLSL ES 1.00.
* Performance was not measured on physical devices in this environment (see Testing below).

## Project format

See [docs/PROJECT_FORMAT.md](docs/PROJECT_FORMAT.md). The sample is generated by
`tools/make_sample_project.py` (requires Pillow):

```sh
python3 -m pip install pillow
python3 tools/make_sample_project.py
```

## Build

Requirements: JDK 17, Android SDK 35 (`platforms;android-35`, `build-tools;35.0.0`).

```sh
./gradlew testDebugUnitTest      # unit tests
./gradlew assembleDebug          # app/build/outputs/apk/debug/app-debug.apk
./gradlew assembleRelease        # app/build/outputs/apk/release/app-release.apk (debug-key signed)
```

GitHub Actions (`.github/workflows/android.yml`) runs the tests, builds both APKs, uploads them as a
workflow artifact, and on pushes publishes them to a rolling `dev-<branch>` pre-release.

## Install

1. Download `LiveVip-debug.apk` (or the release APK) from the dev-build pre-release link on GitHub.
2. Allow installing from your browser or file manager when Android asks.
3. Open **Live VIP**, import a `.mwproj` (or use the bundled sample), then **Set as live wallpaper**.

The release APK is signed with the Android debug key so it can be sideloaded. It is not Play Store signed.

## Testing

Unit tests cover archive safety, path rules, manifest parsing and ranges, PNG header parsing, project
validation (sizes, masks, bounds, memory budget), damping math and particle limits. The GL renderer,
sensors and the system wallpaper flow need a device and are not covered by automated tests here.
