# Third-party software and licenses

Everything the app ships with is free and open source. The app has no paid SDKs, no analytics and no
network permission (`INTERNET` is not requested).

## Runtime (included in the APK)

| Component | Version | License | Use |
|---|---|---|---|
| Kotlin standard library | 2.0.21 | Apache-2.0 | language runtime |
| AndroidX Core KTX | 1.15.0 | Apache-2.0 | Android helpers |
| AndroidX Activity (Compose) | 1.9.3 | Apache-2.0 | `ComponentActivity`, `BackHandler` |
| AndroidX Lifecycle (runtime, viewmodel-compose) | 2.8.7 | Apache-2.0 | ViewModel, lifecycle observers |
| Jetpack Compose BOM, UI, Foundation, Material 3 | 2024.12.01 | Apache-2.0 | user interface |
| Google Gson | 2.11.0 | Apache-2.0 | manifest and settings JSON |

The renderer uses only platform APIs: `android.opengl` (EGL14, GLES20), `android.hardware.SensorManager`,
`android.service.wallpaper.WallpaperService`, `java.util.zip`. No third-party image, GL or sensor libraries.

## Bundled sample content

`app/src/main/assets/samples/neon_warrior.mwproj` was generated by `tools/make_sample_project.py`
from procedural shapes drawn in code. It contains no third-party artwork, photos or fonts, so it
carries no extra license terms beyond this repository's license.
